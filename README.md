# SQLMentor – SQL Mini Project 📊

## 📌 Project Overview

**SQLMentor** is a mini SQL analytics project focused on analyzing user submission data from a learning/competitive platform. The project uses structured CSV data and SQL queries to derive meaningful insights such as user performance, daily and weekly leaderboards, and submission statistics.

This repository is ideal for **SQL beginners to intermediate learners** and demonstrates real-world use of SQL for data analysis.

## 🎯 Objectives

* Practice real-world SQL querying
* Analyze user performance and scoring trends
* Work with date-based aggregations (daily & weekly)
* Build leaderboard-style analytics using SQL
* Strengthen concepts like aggregation, grouping, and ranking

## 🧩 Problem Statements Solved

### Q1️⃣ List all distinct users and their stats

* User name
* Total submissions
* Total points earned

### Q2️⃣ Calculate daily average points for each user

* Groups submissions by user and date

### Q3️⃣ Top 3 users with most positive submissions per day

* Daily leaderboard using ranking

### Q4️⃣ Top 5 users with highest incorrect submissions

* Identifies users with maximum zero/negative scores

### Q5️⃣ Top 10 performers for each week

* Weekly aggregation and ranking of users

## 🛠️ SQL Concepts Used

* `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`
* Aggregate functions: `COUNT()`, `SUM()`, `AVG()`
* Date functions (`DATE`, `WEEK`)
* Subqueries & CTEs
* Window functions (`RANK`, `DENSE_RANK`)
* `HAVING` clause

## 📈 Key Learnings

* Real-world SQL data analysis workflow
* Time-based performance analysis
* Designing leaderboard and ranking queries
* Writing clean and optimized SQL
